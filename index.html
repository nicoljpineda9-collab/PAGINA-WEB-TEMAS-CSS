2.1

Estructura y sintaxis

CSS (Cascading Style Sheets) es el lenguaje que le da color, forma y orden a una página HTML. Todo se escribe con reglas.

Bootstrap: Accordion · Table

estilos.css
/* selector */
h1 {
  color: #E58FB1;     /* propiedad: valor; */
  font-size: 2rem;
}

Resultado

Título con estilo

Una regla le dice al navegador qué elemento modificar y cómo hacerlo. Tiene dos partes:
  • El selector, que indica a qué elementos se aplica.
  • El bloque de declaraciones, entre llaves { }, con una o varias propiedades.

Es lo que está antes de las llaves. Puede ser una etiqueta (p), una clase (.tarjeta) o un id (#menu). 
p      { color: gray; }     /* etiqueta */
.nota  { color: pink; }     /* clase */
#menu  { color: purple; }   /* id */

La propiedad es la característica que quieres cambiar (color, margin) y el valor es cómo debe quedar. Van separados por dos puntos y cada declaración termina con punto y coma. 
propiedad: valor;
background-color: #F8C8DC;

TipoEjemploQué selecciona
Universal*Todos los elementos
EtiquetapTodos los párrafos
Clase.cardElementos con class="card"
ID#menuEl elemento con id="menu"
Atributo[type="text"]Elementos con ese atributo
Descendientediv pLos p dentro de un div
Hijo directodiv > pLos p hijos directos del div
Agrupaciónh1, h2Ambos a la vez

Unidades: px (fija), % (relativa al padre), rem (relativa al tamaño base), vw y vh (ancho y alto de la ventana).
Colores: nombre (pink), hexadecimal (#E58FB1), rgb(229, 143, 177) y hsl(335, 63%, 71%).

  • Olvidar el punto y coma al final de la declaración.
  • No cerrar la llave }: rompe todas las reglas que siguen.
  • Escribir mal la propiedad (colour en vez de color).
  • Usar . o # de más o de menos en el selector.
2.2

Tipos de incorporación de CSS

Hay tres formas de conectar CSS con HTML: interno, externo y en línea.

Bootstrap: Tabs · Table · Accordion

Se escribe dentro de la etiqueta <style>, en el <head> del mismo archivo HTML.

index.html
<head>
  <style>
    p { color: #E58FB1; }
  </style>
</head>

Se escribe en un archivo .css aparte y se conecta con <link>. Es la forma más usada en proyectos reales.

index.html
<head>
  <link rel="stylesheet" href="css/estilos.css">
</head>
css/estilos.css
p { color: #E58FB1; }

Se escribe directamente en la etiqueta con el atributo style. Solo afecta a ese elemento.

index.html
<p style="color: #E58FB1; font-size: 18px;">
  Texto con estilo en línea
</p>
TipoDónde se escribeVentajasDesventajas
InternoEtiqueta <style>Rápido para una sola páginaNo se reutiliza en otras páginas
ExternoArchivo .css con <link>Un solo archivo para todo el sitio, más ordenadoUna petición extra al cargar
En líneaAtributo styleSirve para un cambio puntualDifícil de mantener y muy fuerte en especificidad

Casi siempre el externo: mantiene el HTML limpio y permite usar el mismo CSS en todas las páginas. El interno sirve para pruebas rápidas y el en línea solo para casos muy puntuales.

El estilo en línea gana sobre los otros dos. Entre el interno y el externo, gana el que esté escrito después en el código (si tienen la misma especificidad).

  • Pon el <link> dentro del <head>.
  • Guarda los archivos CSS en una carpeta css/.
  • Evita el estilo en línea, salvo que sea necesario.
2.3

Indentación, herencia y comentarios

Escribir el código ordenado, entender qué se hereda y documentar lo que haces.

Bootstrap: Accordion · List group

Herencia en vivo

Padre (tiene color, fuente y borde)
Hijo: hereda el color y la fuente, pero no el borde.

Es el espacio al inicio de cada línea. No cambia cómo funciona el CSS, pero hace que el código se lea mucho mejor. Lo normal es usar 2 o 4 espacios dentro de cada llave.

Mal

p{color:red;
margin:0;
font-size:16px;}

Bien

p {
  color: red;
  margin: 0;
  font-size: 16px;
}

En VS Code puedes ordenar todo con Shift + Alt + F.

Algunas propiedades pasan automáticamente del elemento padre a sus hijos. Así no tienes que repetir el color o la fuente en cada etiqueta.

Sí se heredan

  • color
  • font-family
  • font-size
  • line-height
  • text-align

No se heredan

  • margin
  • padding
  • border
  • background
  • width y height

  • inherit: obliga a tomar el valor del padre.
  • initial: vuelve al valor por defecto de CSS.
  • unset: hereda si la propiedad es heredable, y si no, usa el valor inicial.
.caja { border: inherit; }

El navegador ignora los comentarios. Sirven para explicar el código, separar secciones o desactivar una línea temporalmente. En CSS solo existe esta forma: 
/* Comentario de una línea */

/* ===== Menú =====
   Comentario de varias líneas */

p {
  color: red;
  /* margin: 0; (línea desactivada) */
}

Ojo: // no es un comentario válido en CSS. En VS Code se comenta con Ctrl + ñ o Ctrl + /.

2.4

Niveles de especificidad

Cuando dos reglas se contradicen, el navegador aplica la que tenga más especificidad.

Bootstrap: Table · Progress · Accordion

estilos.css
p      { color: gray; }   /* 1   */
.azul  { color: blue; }   /* 10  */
#rosa  { color: deeppink; } /* 100 */

Resultado

Solo etiqueta: gana el gris.

Etiqueta + clase: gana la clase.

Etiqueta + clase + ID: gana el ID.

Estilo en líneastyle="..."1000
ID#menu100
Clase, atributo, pseudo-clase.card, [type], :hover10
Etiqueta, pseudo-elementop, ::before1
Universal*0

Se suman los valores de todas las partes del selector. 
#menu .item a:hover
= 100 (id) + 10 (clase) + 10 (pseudo-clase) + 1 (etiqueta)
= 121

nav ul li a
= 1 + 1 + 1 + 1 = 4
Gana el selector con el número más alto.

Si dos reglas tienen la misma especificidad, gana la que esté más abajo en el código. Por eso el orden de las reglas importa.

Pasa por encima de todo lo demás: 
p { color: red !important; }
Úsalo lo menos posible, porque después es muy difícil corregir los estilos.

  • Usa clases en lugar de ids para dar estilo.
  • Evita selectores muy largos.
  • No uses estilos en línea ni !important para arreglar problemas.

Acomoda elementos en una sola dimensión (fila o columna). Se activa en el contenedor padre. 
.contenedor {
  display: flex;
  justify-content: space-between;

Acomoda elementos en dos dimensiones: filas y columnas a la vez.

2.6

Media queries

Permiten aplicar estilos solo cuando se cumple una condición, como el ancho de la pantalla.

Bootstrap: Alert · Badge · Accordion

Tu pantalla ahora

0 px

Móvil

Cambia el tamaño de la ventana y mira cómo se actualiza (según los breakpoints de Bootstrap).

Tip: en el navegador presiona F12 y luego Ctrl + Shift + M para probar el modo de dispositivos.

Se escribe con @media, una condición entre paréntesis y un bloque con las reglas que se aplican: 
@media (min-width: 768px) {
  .portada {
    padding: 60px 0;
  }
}
Esto significa: «cuando la pantalla mida 768 px o más, aplica este padding».

Mobile first: el CSS normal es para móvil y con min-width se agregan cambios para pantallas más grandes. Es lo que usa Bootstrap y lo más recomendado.
Desktop first: el CSS normal es para computador y con max-width se hacen cambios para pantallas más pequeñas. 
/* mobile first */
@media (min-width: 768px) { ... }

/* desktop first */
@media (max-width: 767px) { ... }

CondiciónEjemplo
Ancho mínimo / máximo(min-width: 600px)
Orientación(orientation: landscape)
Modo oscuro(prefers-color-scheme: dark)
Reducir animaciones(prefers-reduced-motion: reduce)
Impresiónprint

Con and se deben cumplir las dos. Con una coma se cumple una u otra. 
/* solo en tablet */
@media (min-width: 600px) and (max-width: 1023px) {
  .morado { background-color: #00839A; }
}

/* en móvil o en horizontal */
@media (max-width: 599px), (orientation: landscape) { ... }
2.7

Pseudo-elementos

Dan estilo a una parte específica de un elemento o agregan contenido sin tocar el HTML. Se escriben con dos puntos dobles ::.

Bootstrap: Accordion · Form control

estilos.css
.nota::before {
  content: "✿ ";
}
.nota::after {
  content: " ✿";
}

Insertan contenido antes o después del contenido del elemento. Siempre necesitan la propiedad content, aunque sea vacía (content: "";).

Texto con adornos

Dan estilo a la primera letra o a la primera línea de un párrafo (efecto de revista). 
p::first-letter { font-size: 2.5rem; color: #E58FB1; }
p::first-line   { font-weight: 700; }

El CSS permite darle estilo a la primera letra y a la primera línea de un texto largo, como si fuera un artículo de una revista, sin agregar etiquetas nuevas al HTML.

Cambia el color del texto cuando el usuario lo selecciona con el mouse.

Selecciona este texto con el mouse para ver el cambio.

Da estilo al texto de ayuda que aparece dentro de un campo vacío.

Cambia el punto o el número de una lista.

2.8

Pseudo-clases

Aplican estilos según el estado o la posición de un elemento. Se escriben con dos puntos :.

Bootstrap: Button · Form switch · Accordion

:hover y :active

:focus

:first-child, :nth-child y :last-child

  • Elemento 1 (primero)
  • Elemento 2
  • Elemento 3
  • Elemento 4
  • Elemento 5 (último)

:checked

  • :hover: cuando el mouse está encima.
  • :active: mientras se mantiene el clic.
  • :focus: cuando el elemento está seleccionado (por ejemplo, un campo de texto).
  • :visited y :link: enlaces visitados y no visitados.
.btn-pc:hover  { background-color: #E58FB1; }
.btn-pc:active { transform: scale(0.95); }

  • :first-child y :last-child: el primer y el último hijo.
  • :nth-child(2): el segundo hijo.
  • :nth-child(odd) y :nth-child(even): impares y pares.
li:nth-child(odd)  { background: #F8C8DC; }
li:nth-child(even) { background: #C9F2E3; }

  • :checked: casilla o interruptor marcado.
  • :disabled: campo desactivado.
  • :required: campo obligatorio.
  • :valid y :invalid: contenido correcto o incorrecto.
input:disabled { opacity: 0.5; }
input:invalid  { border-color: red; }

:not() selecciona todo lo que no cumpla una condición. :focus-within se activa cuando algún hijo tiene el foco. 
p:not(.nota) { color: gray; }
form:focus-within { border-color: #E58FB1; }

Las pseudo-clases (:) hablan del estado de un elemento completo. Los pseudo-elementos (::) hablan de una parte del elemento o de contenido agregado.
2.9

Z-index

Controla qué elemento queda encima de otro cuando se superponen. Entre más alto el número, más cerca del usuario.

Bootstrap: Modal · Toast · Accordion

Capas en vivo

z-index: 1
z-index: 2
z-index: 3

El z-index solo funciona en elementos con position distinto de static (relative, absolute, fixed o sticky), o en hijos de un contenedor flex o grid. 
.capa {
  position: relative;
  z-index: 10;
}

  • Números enteros: z-index: 5; (mayor número = más arriba).
  • Negativos: z-index: -1; (queda detrás del contenido).
  • auto: valor por defecto, sigue el orden del HTML.

Un elemento con position y z-index crea su propio «grupo de capas». Un hijo nunca puede quedar por encima de algo que esté fuera de ese grupo y tenga un z-index mayor, aunque el hijo tenga un número altísimo. Por eso a veces un z-index: 9999 no funciona.

Componentez-index
Dropdown1000
Sticky (menú fijo)1020
Fixed1030
Modal (fondo oscuro)1050
Modal1055
Tooltip1080
Toast1090
